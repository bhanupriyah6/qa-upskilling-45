# QA Upkilling - 45 Days
## Goals
- Learn Python programming
- Understand Git and GitHub
- Learn SQL
- Practice API testing
- Learn automation testing
- Build practical projects

## Day 1
- Installed VS Code
- Installed Python
- Installed Git
- Created first GitHub repository

## Day 2
- Understand Python variables
- Learn data types
- Understand type conversion
- Learn arithmetic, logical and relational operators
- Create five small python programs

## Day 3
- Understand Python conditional statements (if, if-else, if-elif-else).
- Learn match-case.
- Understand for and while loops.
- Learn break, continue, and nested loops.
- Create five small Python programs.

## Day 4
- Understand Python function definition and calling.
- Learn parameters, arguments, and return values.
- Understand default arguments and variable scope.
- Learn pass-by-value vs. pass-by-reference concepts.
- Understand recursion basics.
- Refactor Day 2 and Day 3 programs into reusable functions.
- Create utility functions: isEven(), max_of_three(), and reverseString().

## Day 5
- Understand string immutability and string length.
- Learn string indexing, substring, split, and join.
- Practice replace and trim operations.
- Learn string formatting using f-strings.
- Understand basic regular expressions (Regex).
- Create five programs: reverse a string, count vowels, check anagram, capitalize words, and character frequency map.
